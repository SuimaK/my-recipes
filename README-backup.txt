Мои рецепты — резервная копия приложения

Архив скачивается с GitHub (репозиторий SuimaK/my-recipes, ветка main)
и содержит приложение, локальный модуль распознавания русского текста
и все необходимые статические файлы. Личные рецепты в архив не входят:
скачайте их отдельно кнопкой «Скачать базу рецептов».

Восстановление приложения: распакуйте архив и разместите его содержимое
на статическом HTTPS-хостинге. Главная страница — index.html.
Откройте адрес в Safari и добавьте на экран «Домой».
Открытие index.html напрямую из приложения «Файлы» не заменяет установку PWA.

Восстановление данных: вкладка «Копии» → «Восстановить базу» →
выберите JSON → «Добавить из копии». Импорт добавляет записи и меню,
не удаляя существующие. Рецепты и меню, которые уже есть в книге,
повторно не добавляются.

При смене адреса приложения или устройства загрузите базу из JSON.
Данные хранятся в браузере на вашем устройстве; очистка данных сайта может
их удалить. Храните копии отдельно, например в iCloud Drive.
