# Мои рецепты

Кулинарная книга в браузере: рецепты, меню со списком покупок и резервные копии. Работает без сервера, данные хранятся в браузере (localStorage).

## Возможности

- **Добавление рецептов четырьмя способами:** вручную, по фото (распознавание текста прямо в браузере), из вставленного текста, из файла.
- **Загрузка файлов:** TXT и MD (UTF-8 и Windows-1251), PDF с текстовым слоем, JSON (резервная копия приложения или schema.org), HTML (сохранённая страница рецепта со schema.org-разметкой или обычная). Несколько файлов сразу, перетаскивание в окно, вставка скриншота из буфера.
- **Сборники:** один файл или текст с несколькими рецептами делится автоматически (по `---`, «Рецепт 1», повтору раздела «Ингредиенты» или заголовкам Markdown).
- **Проверка перед сохранением:** список найденных рецептов, правка любого поля, предупреждения («нет ингредиентов»), поиск повторов с выбором «Пропустить / Заменить / Добавить копией», отмена после сохранения.
- Поиск по названию и по нескольким ингредиентам, фильтр по категориям и избранному.
- Меню и общий список покупок с отметками.
- Резервная копия в файл и восстановление из него.

## Запуск

```bash
npm start            # http://127.0.0.1:8080/
```

Можно открыть через любой статический сервер или опубликовать на GitHub Pages (Settings → Pages → Deploy from branch → `main`, папка `/`).

## Тесты

```bash
npm test             # разбор текста (node:test)
npm run test:e2e     # сквозные тесты загрузки в Chromium (нужен пакет playwright)
npm run test:all
```

## Структура

| Файл | Назначение |
|---|---|
| `index.html`, `css/styles.css` | Разметка и стили (светлая и тёмная тема, мобильная вёрстка) |
| `js/parser.js` | Разбор текста, сборников, JSON и HTML в рецепты; поиск повторов |
| `js/importers.js` | Чтение файлов: кодировки, PDF (pdf.js), фото (Tesseract.js) |
| `js/store.js` | Хранилище рецептов и меню |
| `js/app.js` | Интерфейс |
| `vendor/pdfjs` | pdf.js 4.10 (Apache-2.0) |

Распознавание фото загружает Tesseract.js с jsDelivr при первом использовании.
