# Мои рецепты

Кулинарная книга в браузере (iPhone, Safari, PWA): рецепты с фото и заметками, пересчёт порций, разделы, избранное и заготовки, меню со списком продуктов, резервные копии. Данные хранятся на устройстве в IndexedDB.

## Добавление рецептов

- **Вручную.**
- **По фото:** распознавание текста на устройстве (Tesseract), с проверкой распознанного текста.
- **Из текста:** один рецепт или сразу несколько, с разделителем `---` или с заголовком «Ингредиенты» у каждого рецепта. Каждый рецепт проверяется перед сохранением.
- **Из файла:** несколько файлов за раз: PDF (в том числе скан и выбор страниц), TXT и MD (UTF-8 или Windows-1251), HTML (сохранённая страница рецепта со schema.org-разметкой), сборник JSON. Резервная копия, выбранная здесь, открывает восстановление.
- Файлы можно перетащить в окно, скриншот можно вставить из буфера.
- Рецепты, которые уже есть в книге, отмечаются при загрузке. При восстановлении копии повторно не добавляются ни рецепты, ни меню.
- Фото рецепта сохраняется уменьшенным до 1600 px, для списка готовится миниатюра.

## Запуск и тесты

```bash
npm start   # http://127.0.0.1:8080/
npm test    # сквозные тесты в Chromium, нужен пакет playwright
```

## Выпуск новой версии

Измени число `VERSION` в `sw.js`. Это единственное место с номером версии: в `index.html` номера (`?v=`)
не нужны. Установленное приложение подхватит новую версию при следующем запуске.
Кэш библиотек `vendor/` при этом не удаляется; его номер (`vendorCache`) меняется, только если обновлены сами файлы в `vendor/`.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html`, `style.css` | Разметка и стили |
| `app.js` | Рецепты, редактор, хранилище, фото и миниатюры |
| `import.js` | Разбор текста и фото, экран добавления |
| `pdf-import.js` | Разбор книг PDF на рецепты |
| `collection-import.js` | Сборники в тексте, несколько файлов, HTML, кодировки, повторы |
| `menu.js` | Меню и список продуктов |
| `backup.js` | Резервные копии и восстановление без повторов |
| `sw.js` | Офлайн-режим; версия приложения |
| `tests/` | `import.test.mjs` — загрузка рецептов, `app.test.mjs` — офлайн, копии, меню, фото |
| `vendor/pdf`, `vendor/ocr` | pdf.js и Tesseract (Apache-2.0) |
